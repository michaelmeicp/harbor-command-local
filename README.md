# 港灣指揮官 · Harbor Command

一局最多三分鐘的原創瀏覽器微型即時策略。雙岬海峽只有一座公共航標。管理資源、建造船塢，把巡艇派往中央以人數優勢維持訊號。沒有射擊或血量系統。

## 啟動

Node.js 20+，無依賴套件，無須 npm install。

```sh
npm start
# http://127.0.0.1:4100
npm test
```

純靜態伺服器也能玩單人，但不能建立邀請房；請勿直接以 file:// 開啟。這個版本沒有代管的多人服務。

## 第一次啟航

- 預設為微風 AI，按「啟航」或發出首個有效指令才開始計時。想慢慢試，用「航局設定 → 練習 → 開始新局」。手冊可以隨時打開；單人閱讀時會停止計時。
- 點選青港工人（或「全選工人」），再點島上的樹林、石堆。地點存量有限。工人可走陸地、碼頭，不可橫渡水道。
- 選工人 → 造船塢 → 點臨水空地，花 32 木 / 14 石。完工後點船塢造巡艇（23 木 / 8 石）；港務所招募工人（18 木）。信標塔（20 木 / 30 石）在持有浮標時提高訊號，額外信標不疊加。已核准的工程不會因改派工人而取消。
- 「全選巡艇 → 前往浮標」會把巡艇送往中央。距離浮標兩格以內（上下左右步數）艇數較多的一方得分，平手不計。先到 750 獲勝，時間到則較高者獲勝，同分平局。強風 AI 調度更早。
- 鼠標或觸控可點選、拖曳框選。Shift 點選增減；Tab 到海圖後，用方向鍵移動游標、Enter 選取或下令、Esc 清除。選取工人或巡艇也可使用地圖下方／旁邊的群組按鈕。小螢幕用「放大海圖」提高精度；方向鍵或點擊將視野移向所選格。
- 每方最多 14 個單位（含訓練中）及 6 棟建築，每棟最多排隊訓練 2 名。單位可共格，這是避免同隊互相堵住的刻意設計。重開會取代本局；單人不自動存檔。

## 同伺服器雙人

兩個獨立瀏覽器工作階段開啟同一個 Node 伺服器。A 選「航局設定 → 建立邀請房」，B 輸入十位房碼後「加入房間」。不要複製已入座的分頁；用另一個無痕視窗或另一個瀏覽器。預設只監聽本機。不是跨網路媒合或公開網際網路服務，沒有帳號、聊天、排行榜、外部素材或分析追蹤。

伺服器每 200ms 推進規則；瀏覽器以定期輪詢接收快照。房碼和每席權杖分開，權杖只存在當前分頁的 sessionStorage。伺服器檢查席位、順序號碼、地形、資源、數量界限與指令。等待第二人與任一席暫停時不計時；雙方皆恢復才繼續。超過 6 秒未收到心跳即暫停，同分頁刷新可用原席位在額外 20 秒內恢復，逾時房間移除而非判勝。等候室 3 分鐘、房間 45 分鐘、最多 24 房。伺服器重啟會清空房間；無持久資料庫。切到背景的瀏覽器可能節流輪詢，請保持兩邊視窗開啟。

## 驗證與原創來源

`npm test` 在本機重播同種子遊戲，檢查多個開局、有限資源、付費與建造、訓練／地形／數量限制、完整單人勝負、時限；另建實體回環 HTTP 伺服器，讓兩份獨立席位憑證建房、同步移動、測試越權、重播、暫停、斷線、房間到期、靜態檔案界限。SVG 測試驗證渲染、選取與縮放。這些自動測試不是部署或外部網路連線測試。GitHub Actions 設定與本機測試使用相同命令。

- engine.js：本作地圖、規則、雙難度 AI 與定步進模擬。
- board.js：以 SVG primitives 和數學路徑手繪的海岸、地形、碼頭、建築、浮標、工人、巡艇與資源。無下載圖包、外部字型、音樂或其他遊戲資產。
- app.js、index.html、style.css：原創繁體中文介面、操作、教學與本機房間客戶端。
- server.js：原生 Node HTTP 與記憶體中的席位／房間。
